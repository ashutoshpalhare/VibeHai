How to Run

Get VibeHai running locally in under a minute

1. Clone the repository
git clone https://github.com/ashutoshpalhare/VibeHai.git
cd VibeHai
2. Install dependencies
npm install
3. Start development server
npm run dev
4. Production build (optional)
npm run build
npm run preview

Requires Node.js 18+ and npm

Music API

Powered by public JioSaavn-compatible endpoints

VibeHai uses publicly available JioSaavn-compatible APIs to fetch song metadata, album/artist information and playback URLs.

The app includes multiple host fallbacks, request timeouts and response normalization so it remains resilient when one endpoint is unavailable.

You can optionally override the API base URL using an environment variable: 

VITE_JIOSAAVN_API=https://your-custom-endpoint

Note: These are third-party services. Availability and terms can change independently of VibeHai.
