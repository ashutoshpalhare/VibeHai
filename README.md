# VibeHai

**Modern Music Streaming Platform**

VibeHai is a sleek, modern music streaming web app inspired by Spotify.  
It focuses on immersive playback, clean UI, personalized vibes, and a better music discovery experience.

---

## Features

- Clean and modern Spotify-inspired UI
- Immersive music playback experience
- Personalized vibes and recommendations
- Smooth and responsive design
- Built with modern frontend stack

---

## Tech Stack

- **React**
- **Vite**
- **JavaScript**
- Modern CSS / UI libraries

---

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/ashutoshpalhare/VibeHai.git
cd VibeHai
npm install
npm run dev
```
